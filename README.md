# استاندارد توسعه WordPress و وب

مرجع داخلی تیم برای توسعه حرفه‌ای محصولات PHP/WordPress، فرانت‌اند، SEO، Git، پشتیبانی، انتشار محصول و استفاده از دستیارهای هوش مصنوعی.

## مستندات

فهرست کامل در [docs/index.md](docs/index.md) قرار دارد.

## حوزه‌ها

- Frontend: Tailwind CSS و Node.js
- PHP: PSR، Composer، PHPDoc و Exception handling
- WordPress: Theme و Plugin Development
- Quality: Debugging، Testing و Security
- Product: Release، Preview و Customer Support
- SEO: Technical SEO و Core Web Vitals
- AI: workflow و اعتبارسنجی خروجی
- Git: branch، commit، PR و release

## اصول repository

1. کد باید قابل نگهداری، تست و بازبینی باشد.
2. secret و داده خصوصی هرگز commit نشود.
3. تغییرات با commitهای کوچک و معنادار ثبت شوند.
4. مستندات همراه تغییرات به‌روز شوند.
5. قوانین بیرونی که ممکن است تغییر کنند با «نیاز به بررسی» علامت‌گذاری شوند.

## مرجع اصلی AI

برای workflow دستیارهای هوش مصنوعی، [ai-assistant-workflow.md](docs/ai-assistant-workflow.md) را بخوانید. منبع اصلی اعلام‌شده برای این حوزه `https://llm.bestjustify.ir/` است؛ وضعیت دسترسی/محتوای جاری آن باید دوره‌ای بررسی شود.
